[요구사항 정의서] 
복지용구 위탁소독 웹 접수 및 카카오 알림톡 CRM 구축

1. 사업 개요
• 프로젝트명: 광주·전남 복지용구 위탁소독 전용 수거 접수 & 이력관리 시스템 구축
• 목적: 복지용구 대여사업소(거래처)의 수거/소독 신청 편의성 제공, 카카오 알림톡 기반 4단계 자동 상태 안내, PDF 소독증명서 자동 생성 및 공단 제출용 엑셀 이력 관리 시스템 구축
• 주요 타깃: 광주·전남 지역 복지용구 대여사업소 (약 230개소) 및 현장 수거/배송 기사
• 핵심 과업: 모바일 웹 접수폼 + 관리자 대시보드(CRM) + 카카오 알림톡 API 연동 + PDF 소독증명서 생성 모듈

2. 상세 기능 요구사항 (5대 모듈)

[모듈 1] 거래처용 모바일 웹 접수폼
• 별도 앱 설치 없는 URL/QR 접속 방식 (모바일/PC 반응형)
• 사업소 정보 선택 및 수거 희망일/장소(사업소 또는 자택 주소) 입력
• 의뢰 품목 카운터 (전동침대, 휠체어, 기타 소형 용구 등)
• A/S 점검 요청 및 기타 비고사항 입력 체크박스

[모듈 2] 관리자 CRM 대시보드
• 수거/소독 진행 현황판 (접수대기 ➔ 수거예정 ➔ 입고/소독중 ➔ 소독완료 ➔ 배송완료)
• 권역별(광주/목포/순천 등) 픽업 건 필터링 및 픽업 담당 기사 지정
• 상태 변경 시 카카오 알림톡 자동 발송 트리거 연동

[모듈 3] 카카오 알림톡 API 연동 (비즈뿌리오/쏠라피)
• 1단계 (수거접수): 수거 예정일 및 담당 기사 안내
• 2단계 (입고완료): 센터 입고 및 소독 진행 안내
• 3단계 (소독완료): [PDF 소독증명서 다운로드] 버튼 내장 메시지 발송
• 4단계 (배송완료): 인수 확인 및 출고 완료 안내

[모듈 4] 전자 소독증명서 (PDF 연동)
• 공단 표준 양식에 DB 데이터(사업소, 품목, 시리얼, 소독일, 직인) 자동 삽입
• 알림톡 버튼 클릭 시 로그인 없이 안전한 단축 URL로 PDF 인쇄/다운로드 가능

[모듈 5] 데이터 관리 및 엑셀 추출
• 국민건강보험공단 현장 실사용 '위탁소독 처리 대장' 엑셀 다운로드
• 기간별/거래처별 소독 처리 대수 통계 제공

3. 산출물 및 전달 요구사항
• 소스 코드 전체 및 DB 스키마 명세서
• 관리자 페이지 사용 가이드 문서 (PDF)
• 카카오 비즈니스 알림톡 템플릿 검수 대행 및 승인 완료건
• 하자 보수 지원 (최소 1개월 ~ 3개월)
