## DEC-003 — 1단계 접수번호 표시 형식 승인

- 결정: 접수번호는 DB 시퀀스 기반 `R-{10자리 일련번호}` 형식을 사용한다. 예시는 `R-0000000001`이다. 런타임 트랜잭션 롤백 등으로 발생한 번호 공백을 허용하고 이미 소비한 번호는 재사용하지 않는다.
- 이유: 날짜별 `MAX+1` 방식의 동시성 충돌을 피하고, 단일 DB 시퀀스로 중복 없는 접수번호를 단순하게 부여하기 위해서다.
- 영향: 데이터 모델과 이후 구현·화면·PDF·엑셀의 접수번호 표현을 이 형식으로 통일한다. 번호는 순서 식별용이며 연속성을 업무 완료 조건으로 사용하지 않는다.
- 재검토 조건: 실제 운영에서 날짜 포함, 거래처별 번호 또는 법정 서식에 따른 번호 규칙이 요구되는 경우
- 사용자 승인: 2026-08-22 21:55 KST, Product Owner 명시 승인
