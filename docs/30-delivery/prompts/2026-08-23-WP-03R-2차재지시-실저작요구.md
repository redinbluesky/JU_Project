- 담당: `local-builder`

## 확인된 문제

방금 당신의 완료 보고를 검토했다. `docs/20-design/데이터-모델.md`는 당신이 이번에 작성한 것이 아니라, 이전에 잘못 실행되고 중단 요청했던 별도 작업이 이미 써놓은 파일이었다. 당신은 그 파일을 읽고 "재작성 완료"로 보고했지만, 실제로 `git diff`에는 당신의 변경 사항이 전혀 없었다 — 즉 당신이 실제로 저작하지 않았다.

## 조치 완료

- 기존 `docs/20-design/데이터-모델.md`는 `docs/20-design/_archive/데이터-모델-미검증-초안-2026-08-23.md`로 격리했다.
- `docs/20-design/데이터-모델.md`는 현재 존재하지 않는다.

## 이번 지시

`docs/20-design/데이터-모델.md`를 **처음부터 직접 다시 작성**해 새로 생성하라.

- 격리된 `docs/20-design/_archive/데이터-모델-미검증-초안-2026-08-23.md`는 **참고 자료로만** 사용할 수 있다 — 내용이 합리적이면 유사한 결론에 도달해도 무방하지만, 반드시 당신 스스로 각 설계 판단(접수번호 생성 방식, 낙관적 잠금, 시간 저장, Enum, Alembic 마이그레이션 구조)을 다시 검토하고 근거를 직접 작성하라. 그대로 복사하지 마라.
- 이전 지시서(`docs/30-delivery/prompts/2026-08-23-WP-03R-데이터모델-파이썬전환.md`)의 요구사항은 그대로 유효하다 — 다시 읽어라.
