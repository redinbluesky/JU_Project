# DEV-002 실행 지시서 (3/6) — Alembic 초기화 + 마이그레이션 리비전 3개

담당: `local-builder` | 대상: `alembic.ini`, `migrations/`

## 배경

2/6(SQLAlchemy 모델) 완료 확인됨. 이번엔 **3단계, Alembic 마이그레이션만** 작성한다. 짧게 끝내라.

## 읽을 문서

`docs/20-design/데이터-모델.md` 7절(Alembic 마이그레이션 구조), 10절(초기 데이터), 11절

## 작업

1. `uv run alembic init migrations` 실제 실행 (이미 `migrations/` 폴더가 비어있으면 그 안에 초기화, 있으면 충돌 처리)
2. `alembic.ini`에서 `sqlalchemy.url`을 `sqlite:///runtime/db/ju-project.db`로 설정
3. `migrations/env.py`에서 `target_metadata`를 `app.main.db.base.Base.metadata`로 연결 (models.py를 import해서 메타데이터에 테이블이 등록되게 할 것)
4. 리비전 3개 작성 (Alembic revision 명령이나 직접 파일 작성 — 자유):
   - 리비전 1: `business_offices` 테이블 생성 + 초기 사업소 3건 INSERT (가상 이름 OFFICE_A/B/C, DEC-007에 따라 그대로 사용)
   - 리비전 2: `requests` 테이블 생성(전체 컬럼/제약/인덱스) + `request_no_counter` 테이블 생성 및 1행 시딩
   - 리비전 3: `request_status_history` 테이블 생성(전체 컬럼/제약/인덱스)

이번엔 `alembic upgrade` 실제 실행까지는 하지 마라 (4/6에서 진행).
