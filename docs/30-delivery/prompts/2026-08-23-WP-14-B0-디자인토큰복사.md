# WP-14-B0 지시서 — Wanted CSS 토큰 복사만

담당: `local-builder`
수정 허용 경로: `app/static/css/`만

## 이번 작업은 복사 1개만 수행

다른 화면·템플릿·React·JS·API 코드는 이번 작업에서 건드리지 마라.

원본:
```
D:\Tmp\Wanted Design System\tokens\fonts.css
D:\Tmp\Wanted Design System\tokens\colors.css
D:\Tmp\Wanted Design System\tokens\typography.css
D:\Tmp\Wanted Design System\tokens\layout.css
D:\Tmp\Wanted Design System\tokens\base.css
```

대상:
```
D:\llm\JU_Project\app\static\css\tokens\
```

작업:
1. 대상 디렉터리 생성
2. 위 5개 CSS 파일을 원본 내용 그대로 복사
3. `app/static/css/wanted.css`를 작성하되 다음 5개만 import:
   `./tokens/fonts.css`, `colors.css`, `typography.css`, `layout.css`, `base.css`
4. 실제 파일 존재와 줄 수를 확인

검증:
```
python -c "from pathlib import Path; p=Path('app/static/css'); print([(str(x), x.stat().st_size) for x in sorted((p/'tokens').glob('*.css'))]); print((p/'wanted.css').exists())"
```

코드·템플릿·테스트는 작성하지 마라. 완료 보고는 5줄 이내로 하고 반드시 실제 파일 생성 결과를 포함하라. 완료 전에는 reasoning을 반복하지 말고 즉시 파일 복사와 검증을 실행하라.
