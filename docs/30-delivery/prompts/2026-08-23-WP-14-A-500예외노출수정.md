# WP-14-A 지시서 — 500 응답 내부 예외 메시지 노출 수정

담당: `local-builder` | 수정 허용 경로: `app/main/api/requests.py`, `tests/test_error_responses.py`

## 문제

quality-gate가 `app/main/api/requests.py`에서 예기치 않은 예외의 원문을 HTTP 500 detail에 포함하는 관측을 발견했다.
예: `detail=f"상태 변경 실패: {str(e)}"`

## 작업

1. 상태전이·접수 생성·접수 수정 API의 예상 밖 Exception 응답에서 내부 예외 원문을 제거하라.
2. 클라이언트에는 안전한 고정 메시지만 반환하라:
   - `상태 변경 중 서버 오류가 발생했습니다.`
   - `접수 생성 중 서버 오류가 발생했습니다.`
   - `접수 수정 중 서버 오류가 발생했습니다.`
3. 자동화 테스트에서 monkeypatch로 RuntimeError를 유도해 500 response detail에 RuntimeError 원문/DB 경로가 포함되지 않는지 검증하라.
4. 기존 ValueError 409, ValidationError 422, StaleDataError 409 동작은 유지하라.

## 검증

```
uv run pytest tests/test_error_responses.py -v
uv run pytest tests/ -q
```

이번 작업에서 UI·모델·마이그레이션은 수정하지 마라. 완료 보고에는 실제 테스트 결과를 포함하라.
