# WP-13-A 지시서 — 자동화 테스트·핵심 불변조건 독립 검증

담당: `quality-gate`
수정 허용 경로: `docs/40-quality/테스트-결과.md`, `docs/40-quality/결함-목록.md`만.

## 중요

이전 WP-13 통짜 실행은 컨텍스트 초과로 산출물 없이 종료됐다. 이번에는 이 청크의 범위만 처리하고, 읽을 파일도 제한한다. 긴 전체 문서를 한 번에 읽지 마라.

## 읽을 파일

- `docs/40-quality/인수조건-체크리스트.md`의 QA-041~048과 14절만
- `docs/20-design/시스템-설계.md` 7.3, 10, 13, 14절
- `docs/20-design/데이터-모델.md` 3~10절
- `tests/`의 테스트 파일명 목록과 통합 테스트 2개(`test_integration_flow.py`, `test_integration_artifacts.py`)
- 구현 코드: `app/main/models/models.py`, `app/main/services/request_service.py`, `app/main/services/pdf_service.py`, `app/main/services/excel_service.py`, `app/main/services/excel_utils.py`

## 실행

실제 실행:
```
uv run pytest tests/ -v
```

## 판정 범위

다음만 실제 증거와 함께 판정하라:
- 전체 자동화 테스트 결과
- 상태 순차전이·불법전이·이력 sequence
- 실패 시 상태/이력/카운터 부분 저장 방지
- StaleDataError 409 및 자동 재시도 없음
- PDF 상태 권한·프로토타입 표시
- 목록·통계·엑셀 필터 공유
- XLSX 10열·DB 정합성·formula cell 0
- SQLite 재오픈 보존
- 개인정보·자격증명 미사용

## 산출물

`테스트-결과.md`를 새 내용으로 작성하라:
- 실행 명령과 실제 `pytest` 결과
- 테스트 파일별 통과 수
- 위 핵심 항목별 증거 경로
- 아직 검증하지 않은 UI/API 항목은 쓰지 말고 `WP-13-B에서 판정 예정`으로 표시

`결함-목록.md`에는 이 청크에서 발견한 결함만 기록하라. 없으면 “확인된 결함 없음”과 미검증 위험을 구분해 기록하라.
