# WP-14-B2A-검증 지시서 — 현재 목록 화면 테스트만 추가

담당: `local-builder`
수정 허용 경로: `tests/test_ui_list.py` 하나만

현재 작업 트리에 이미 WP-14-B2A 목록 화면 부분 구현이 있다. 앱 코드(`app/server.py`, `app/static/css/app.css`, `app/templates/**`)는 절대 수정하지 마라.

## 테스트 작성

`tests/test_ui_list.py`에 TestClient + 임시 SQLite dependency override를 작성하라.

검증:
1. `GET /admin/requests` → 200
2. HTML에 `접수 목록`, 시작일/종료일/사업소/상태 label, 테이블 헤더, 엑셀 다운로드, 상세 링크가 존재
3. `role="status"`, `aria-live="polite"` 존재
4. seed 접수 1건이 접수번호·상태 텍스트·전체수량으로 렌더링
5. 빈 목록에서 empty state 표시
6. 필터 query를 붙여도 200이고 선택값 유지
7. `/static/css/app.css`와 `/static/css/wanted.css` 연결
8. 기존 API 회귀는 전체 테스트로 확인

## 검증 명령

```
uv run python -c "import app.server; print('import ok')"
uv run pytest tests/test_ui_list.py -v
uv run pytest tests/ -q
```

현재 앱 구현에 문제가 있어 테스트가 실패하면, 먼저 실패 원인을 보고하라. 이번 지시서에서는 앱 코드를 수정하지 마라.
