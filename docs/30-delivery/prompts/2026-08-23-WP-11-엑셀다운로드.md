# WP-11 실행 지시서 — 엑셀 다운로드 + 필터 정합성 + 수식 인젝션 테스트

담당: `local-builder` | 수정 허용 경로: `app/main/services/`, `app/main/api/requests.py`, `tests/test_excel_download.py`

## 이번 청크 범위

WP-10까지 완료됐다. 이번에는 **현재 목록 필터 결과를 XLSX로 다운로드**하는 기능만 구현한다. WP-12 통합검증은 별도 작업이다.

## API

```text
GET /api/requests/export
```

목록 API와 동일한 쿼리 파라미터:
- `pickup_date_from`
- `pickup_date_to`
- `business_office_id`
- `current_status`

규칙:
- 기간은 `pickup_date` 기준
- 조건은 AND 결합
- from > to는 422
- 목록 API와 동일한 행 집합·정렬을 사용

## XLSX 요구사항

openpyxl로 생성하고 `runtime/xlsx/`에 저장한다. 테스트는 tmp_path를 주입해 runtime을 오염시키지 마라.

필수 10개 열을 정확히 다음 순서로 작성하라:

```text
접수번호
사업소
수거 희망일
수거 장소 유형
수거 주소
전동침대 수량
휠체어 수량
기타 소형 용구 수량
상태
완료일
```

- 사업소는 business_office_id가 아니라 BusinessOffice.name으로 표시
- 상태는 RequestStatus.value
- 행 수는 현재 필터 결과와 동일
- 날짜는 ISO 또는 승인된 명확한 날짜 형식
- 헤더 포함, 0건이어도 유효한 XLSX와 헤더 10개 생성
- 기존 `app/main/services/excel_utils.py`의 `sanitize_excel_cell()`을 주소 등 사용자 입력 문자열에 반드시 적용
- `=`, `+`, `-`, `@` 시작 문자열이 저장 후 openpyxl 재로드 시 data_type='f'가 아니어야 함

## 구현 권장 위치

- `app/main/services/excel_service.py`: `generate_requests_xlsx(db, filters, out_dir=None) -> Path`
- `app/main/api/requests.py`: export 라우터
- 기존 목록/통계/PDF/상태 API는 변경하지 마라

## pytest 필수

`tests/test_excel_download.py` 신규 작성. 임시 SQLite + StaticPool로 사업소 2개와 접수 4건을 준비하라.

최소 테스트:
1. 기본 다운로드 200 + application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
2. 헤더 10개 이름·순서 정확성
3. 행 수 = 목록 필터 결과 행 수
4. 기간 필터가 pickup_date 기준인지 확인
5. 사업소·상태·복합 필터 정합성
6. 0건 결과도 헤더 10개인 유효한 XLSX
7. DB 원본 값과 XLSX 각 열 값 대조
8. 주소 `=SUM(1+1)`, `+cmd`, `-cmd`, `@cmd`를 저장 후 재로드해 모두 data_type='s'인지 확인
9. 기존 API 회귀

## 검증 명령
