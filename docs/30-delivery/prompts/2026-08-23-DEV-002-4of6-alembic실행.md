# DEV-002 실행 지시서 (4/6) — alembic upgrade 실제 실행 검증

담당: `local-builder` | 대상: `runtime/db/`

## 배경

3/6(Alembic 리비전 3개) 완료 확인됨. 이번엔 **4단계, 실제 DB에 마이그레이션 적용만** 한다. 짧게 끝내라.

## 작업

1. `runtime/db/` 디렉터리가 없으면 생성
2. `uv run alembic upgrade head` 실제 실행
3. 실행 후 `runtime/db/ju-project.db` 파일이 생성됐는지 확인
4. sqlite3로 직접 접속해서 테이블 목록과 초기 데이터 확인:
   ```
   uv run python -c "
   import sqlite3
   conn = sqlite3.connect('runtime/db/ju-project.db')
   cur = conn.cursor()
   cur.execute(\"SELECT name FROM sqlite_master WHERE type='table'\")
   print('tables:', cur.fetchall())
   cur.execute('SELECT * FROM business_offices')
   print('offices:', cur.fetchall())
   cur.execute('SELECT * FROM request_no_counter')
   print('counter:', cur.fetchall())
   "
   ```
5. `PRAGMA foreign_keys` 설정이 세션에서 적용되는지도 확인 (session.py의 이벤트 리스너가 실제로 동작하는지)

## 완료 보고 형식

```
4/6 완료
- alembic upgrade head 실행 결과: (성공/실패, 실제 출력)
- DB 파일 생성 확인: (경로, 크기)
- 테이블 목록: (실제 조회 결과)
- 초기 사업소 데이터: (실제 조회 결과 3건)
- request_no_counter 초기값: (실제 조회 결과)
```

실패하면 실패했다고 정직하게 보고하고 원인을 분석하라. 성공한 것처럼 꾸미지 마라.
