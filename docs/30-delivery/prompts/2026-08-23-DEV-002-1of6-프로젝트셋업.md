## 작업

1. `D:\llm\JU_Project`에 `pyproject.toml` 작성. 의존성: fastapi, uvicorn[standard], sqlalchemy>=2.0, alembic, pydantic>=2, jinja2, python-multipart, reportlab, openpyxl, pytest, httpx. Python 요구버전 3.11.
2. `uv venv` 실행 (가상환경 생성)
3. `uv pip install -e .` 또는 `uv sync` 로 의존성 설치 실제 실행
4. 설치 성공 여부 확인 (`uv pip list` 또는 동등 명령으로 fastapi/sqlalchemy/alembic 설치 확인)
