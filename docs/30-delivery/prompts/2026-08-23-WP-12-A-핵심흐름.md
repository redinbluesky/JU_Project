# WP-12 실행 지시서 (A) — 핵심 업무 흐름 통합 테스트만

담당: `local-builder` | 수정 허용 경로: `tests/test_integration_flow.py`

## 매우 제한된 범위

이번 작업은 앱 코드를 수정하지 말고, **접수 생성→수정→상태전이→배송완료까지의 핵심 API 흐름 테스트 1개 파일만 작성**하라.
PDF/XLSX/통계/재시작 검증은 다음 청크에서 한다.

## 테스트 내용

`tests/test_integration_flow.py`에 임시 SQLite 파일 또는 StaticPool fixture를 작성하고 실제 FastAPI TestClient 라우터를 호출하라.

하나의 테스트에서 다음을 검증:
1. 사업소와 RequestNoCounter 시딩
2. POST /api/requests → 201, RECEIVED
3. PATCH /api/requests/{id} → 200, 주소/수량 변경
4. PATCH /api/requests/{id}/status target=PICKED_UP → 200
5. target=DISINFECTED → 200
6. target=DELIVERED → 200, completion_date not null
7. DB에서 현재 상태 DELIVERED, 상태 이력 4건, sequence [1,2,3,4] 확인
8. 잘못된 입력 하나가 422이고 Request count가 증가하지 않음

기존 테스트 파일은 수정하지 마라. 앱 코드도 수정하지 마라.

## 실행

```
uv run pytest tests/test_integration_flow.py -v
uv run pytest tests/ -q
```

반드시 먼저 `write_file`로 파일을 만든 뒤 두 명령을 실제 실행하라. 파일을 만들지 못했으면 완료라고 보고하지 마라.
