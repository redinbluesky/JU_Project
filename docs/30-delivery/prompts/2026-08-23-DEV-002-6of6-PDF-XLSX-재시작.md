# DEV-002 실행 지시서 (6/6, 최종) — PDF/XLSX 최소 생성 + 재시작 보존 검증

담당: `local-builder` | 대상: `app/main/services/` 또는 `tests/`

## 배경

5/6까지 모두 완료 확인됨 (셋업, 모델, Alembic, DB 마이그레이션, FastAPI 기동). 마지막 단계다. 짧게 끝내라.

## 작업

### 1. PDF 최소 생성 (reportlab)
간단한 스크립트나 pytest 테스트로:
- reportlab로 1페이지짜리 PDF 생성 ("기술 프로토타입 — 공단 제출용 아님" 텍스트 포함, 시스템설계 13절)
- `runtime/pdf/test.pdf`에 저장
- 실제로 파일이 생성되고 크기가 0보다 큰지 확인

### 2. XLSX 최소 생성 (openpyxl)
- openpyxl로 워크북 생성, 헤더 10개 열(데이터모델 없어도 시스템설계 14절의 필수 10열: 접수번호/사업소/수거희망일/수거장소유형/수거주소/전동침대수량/휠체어수량/기타소형수량/상태/완료일)
- 수식 인젝션 방지 테스트: `=SUM(1+1)` 같은 문자열을 셀에 넣었을 때 텍스트로 안전하게 처리되는지 실제 확인
- `runtime/xlsx/test.xlsx`에 저장

### 3. 재시작 보존 검증
- 현재 `runtime/db/ju-project.db`에 있는 사업소 데이터 개수를 확인 (이미 3건 있음)
- Python 프로세스를 새로 열어서 (즉 새 `uv run python -c ...` 호출) 다시 조회해도 동일한 3건이 나오는지 확인 → "재시작 후 보존" 모사 검증
