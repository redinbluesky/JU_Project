# DEV-002 실행 지시서 (5/6) — FastAPI 부트스트랩 + uvicorn 기동 검증

담당: `local-builder` | 대상: `app/main.py`, `app/main/api/`

## 배경

4/6(DB/마이그레이션) 완료 확인됨 — 5개 테이블 생성, 초기 데이터 확인. 이번엔 **5단계, FastAPI 최소 부트스트랩만** 한다. 접수/상태전이 등 업무 로직은 아직 만들지 않는다. 짧게 끝내라.

## 작업

1. `app/main.py` 작성 — FastAPI 앱 생성, `/health` 헬스체크 엔드포인트 하나만 (DB 연결 확인 포함: `SELECT 1` 실행해서 성공하면 `{"status": "ok", "db": "connected"}` 반환)
2. `uv run uvicorn app.main:app --host 127.0.0.1 --port 8000` 로 백그라운드 실행 (터미널 도구의 background 옵션 사용)
3. 기동 후 실제로 `curl http://127.0.0.1:8000/health` (또는 python requests/httpx)로 헬스체크 호출해서 응답 확인
4. 확인 후 프로세스 종료

## 완료 보고 형식

```
5/6 완료
- app/main.py 작성: (verified 여부)
- uvicorn 기동 결과: (성공/실패, 실제 로그)
- /health 호출 결과: (실제 HTTP 응답 body와 status code)
- 프로세스 종료: (확인)
```

실제로 서버를 띄우고 HTTP 요청을 보내지 않고 "될 것이다"라고 보고하면 승인하지 않는다.
