# WP-14-B2A 지시서 — Wanted 목록 화면만 구현

담당: `local-builder`
수정 허용 경로: `app/server.py`, `app/templates/requests/list.html`, `app/static/css/app.css`, `tests/test_ui_list.py`

## 이번 작업 범위

**목록 화면 하나만** 구현한다. 상세 화면·통계 화면·상태 변경 화면은 건드리지 마라.

## 화면

```text
GET /admin/requests
```

Jinja2Templates와 기존 `list_requests()` 서비스를 사용한다.

필수:
- `pickup_date_from`, `pickup_date_to`, `business_office_id`, `current_status` 필터
- 접수번호·사업소·수거 희망일·상태·전체 수량 표
- 상태 텍스트 + badge/chip
- 상세 링크는 `/admin/requests/{id}`로만 연결하고 상세 페이지는 이번에 만들지 않는다
- 엑셀 다운로드 링크 `/api/requests/export`
- 0건 empty state
- `role="status"`, `aria-live="polite"`
- 모바일 375px 가로 스크롤 없음
- Wanted 토큰과 `app.css` 사용

## 중요 구현 주의

`app/server.py`에서 FastAPI의 `Request`와 SQLAlchemy 모델 `Request`를 같은 이름으로 import하지 마라.
반드시 다음처럼 alias를 사용하라:

```python
from fastapi import Request
from app.main.models.models import Request as RequestModel
```

라우트 추가로 기존 `/requests/new`, `/health`, `/api/**`가 깨지지 않아야 한다.
