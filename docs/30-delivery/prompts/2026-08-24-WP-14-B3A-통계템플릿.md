# WP-14-B3A 지시서 — 통계 화면 템플릿만 작성

담당: `local-builder`
수정 허용 경로: `app/server.py`, `app/templates/dashboard/index.html`만

이번 작업은 통계 화면의 서버 라우트와 Jinja 템플릿만 작성한다. CSS와 테스트는 다음 청크에서 한다. 기존 API와 기존 화면을 수정하지 마라.

## 즉시 실행 규칙

긴 분석을 반복하지 말고 먼저 파일을 작성하라. `app.server`의 기존 FastAPI Request와 SQLAlchemy RequestModel alias를 유지하라.

## 구현

- `GET /admin/dashboard`
- 기존 `get_statistics_summary()` service를 SessionLocal로 호출
- 템플릿에 `stats`와 `filters` 전달
- `/admin/dashboard`에서 통계 값 표시:
  - 전체 접수 건수
  - 사업소별 접수 건수
  - 상태별 접수 건수
  - 전동침대/휠체어/기타/전체 수량
- 기간 from/to query parameter 전달·유지
- `base.html` 확장
- Wanted token CSS 클래스는 기존 클래스만 사용하고 새 CSS는 이번에 만들지 마라
- `role="status"`, `aria-live="polite"`

## 검증

```
uv run python -c "import app.server; print('import ok')"
```

이번에는 pytest 파일을 만들지 말고, 실제 두 파일을 작성한 뒤 import 결과와 변경 파일을 보고하라. 다른 파일은 수정하지 마라.
