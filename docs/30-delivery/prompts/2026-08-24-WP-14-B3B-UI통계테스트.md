# WP-14-B3B 지시서 — 통계 화면 CSS·테스트만

담당: `local-builder`
수정 허용 경로: `app/static/css/app.css`, `tests/test_ui_dashboard.py`만

현재 `GET /admin/dashboard`와 `app/templates/dashboard/index.html`은 이미 작성되어 있다. `app/server.py`, 템플릿, API 코드는 수정하지 마라.

## CSS

기존 Wanted 토큰을 재사용해 통계 화면을 보완하라.
- `.detail-grid`, `.detail-panel`, `.detail-list`, `.detail-total`은 기존 스타일 재사용 또는 이미 존재하면 수정하지 않음
- 통계 화면에 필요한 최소 클래스만 추가
- 375px에서 detail-grid 1열
- 가로 스크롤 없음
- 상태 badge는 색상+텍스트 유지
- 큰 숫자만 강조하는 장식적 dashboard 금지

## 테스트

`tests/test_ui_dashboard.py` 신규 작성:
1. GET `/admin/dashboard` 200
2. 전체 접수 건수·품목 수량·사업소별·상태별 항목 렌더링
3. 기간 필터 value 유지 및 통계 값 변경
4. 0건 empty state
5. role=status·aria-live
6. Wanted CSS 연결
7. 모바일 media query/overflow CSS 확인
8. 기존 접수폼·목록·상세/API 회귀

임시 SQLite dependency override를 사용하고 기존 테스트 파일은 수정하지 마라.

## 검증

```
uv run pytest tests/test_ui_dashboard.py -v
uv run pytest tests/ -q
```
