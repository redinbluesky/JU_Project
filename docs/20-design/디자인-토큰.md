## 1. 색상 토큰

| 토큰 | 값 | 용도 |
|------|-----|------|
| --color-primary | #1A73E8 | 주요 버튼, 링크 |
| --color-primary-hover | #1557B0 | 호버 상태 |
| --color-success | #0D7A3E | 성공/완료 상태 |
| --color-warning | #D97706 | 경고/대기 상태 |
| --color-error | #C5241F | 오류 상태 |
| --color-info | #1A73E8 | 정보 표시 |
| --color-text | #212121 | 기본 텍스트 |
| --color-text-secondary | #5F6368 | 보조 텍스트 |
| --color-border | #DADADA | 경계선 |
| --color-bg | #FFFFFF | 배경 |
| --color-bg-secondary | #F7F9FA | 보조 배경 |
| --color-bg-disabled | #E8E8E8 | 비활성화 배경 |

**상태 색상 규칙**:
- 색상만으로 상태를 구분하지 않음
- 모든 상태는 아이콘 + 텍스트 + 색상 조합으로 표현
- 상태별 색상:
  - 접수: --color-info (파랑)
  - 수거완료: --color-warning (주황)
  - 소독완료: --color-success (초록)
  - 배송완료: --color-success (초록, 더 진한 톤)

- 모든 상태는 텍스트로 명시

## 7. 반응형 토큰

| 토큰 | 값 | 용도 |
|------|-----|------|
| --breakpoint-mobile | 375px | 모바일 기준 |
| --breakpoint-tablet | 768px | 태블릿 기준 |
| --breakpoint-desktop | 1200px | 데스크톱 기준 |

**모바일 우선**:
- 모바일 너비 이하에서는 세로 배치
- 태블릿 너비에서는 2열 그리드
- 데스크톱 너비 이상에서는 3열 그리드 또는 가로 배치

## 9. 사용 규칙

1. 모든 화면은 디자인 토큰을 사용해야 함
2. 임의 색상과 간격 허용 안 함
3. 색상만으로 상태 구분 금지
4. 모든 입력에 명시적 레이블과 오류 메시지 필수
5. 모바일 우선 설계, 반응형으로 구현
