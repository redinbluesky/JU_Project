## 1. 화면 흐름

### 1.1 접수폼

**목적**: 현장 담당자가 복지용구 수거를 접수한다.

**사용자 행동**:
1. 사업소 선택
2. 수거 희망일 선택
3. 수거 장소 유형 선택 (사업소/자택)
4. 수거 주소 입력
5. 품목 수량 입력 (전동침대, 휠체어, 기타 소형 용구)
6. 접수 생성

**화면 흐름**:
```
[접수폼 화면]
├── 사업소 선택 (드롭다운 또는 라디오 버튼)
├── 수거 희망일 선택 (날짜 입력)
├── 수거 장소 유형 선택 (사업소/자택)
├── 수거 주소 입력 (항상 활성화)
├── 품목 수량 입력 (카운터 형태)
│   ├── 전동침대 수량
│   ├── 휠체어 수량
│   └── 기타 소형 용구 수량
└── 접수 생성 버튼
```

### 1.2 접수 목록/상세

**목적**: 관리자가 접수 내역을 조회하고 상세 정보를 확인하며 상태를 변경한다.

**사용자 행동**:
1. 목록에서 필터 적용 (기간, 사업소, 상태)
2. 목록에서 접수 건 선택
3. 상세 정보 확인
4. 상태 변경 (접수 → 수거완료 → 소독완료 → 배송완료)
5. 소독완료 상태부터 PDF 다운로드

**화면 흐름**:
```
[목록 화면]
├── 필터 영역 (기간, 사업소, 상태)
├── 접수 목록 테이블
│   ├── 접수번호
│   ├── 사업소
│   ├── 수거 희망일
│   ├── 상태
│   └── 전체 수량
└── 엑셀 다운로드 버튼

[상세 화면]
├── 접수번호
├── 사업소
├── 수거 희망일
├── 수거 장소 유형과 주소
├── 품목별 수량
├── 현재 상태
├── 생성 시각
├── 모든 상태 변경 시각
├── 완료일
├── 상태 변경 버튼
└── PDF 다운로드 버튼 (소독완료 상태부터)
```

### 1.3 통계 대시보드

**목적**: 관리자가 접수 현황을 집계하여 파악한다.

**사용자 행동**:
1. 기간 선택
2. 통계 항목 확인

**화면 흐름**:
```
[통계 대시보드]
├── 기간 선택 필터
├── 기간별 접수 건수
├── 사업소별 접수 건수
├── 상태별 접수 건수
├── 전체 품목 총수량
├── 전동침대 총수량
├── 휠체어 총수량
└── 기타 소형 용구 총수량
```

## 2. 필드, 검증 규칙, 오류 상태

### 2.1 접수폼 필드

| 필드 | 타입 | 필수 | 검증 규칙 | 오류 메시지 |
|------|------|------|-----------|------------|
| 사업소 | 선택 | 예 | 고정된 1~3개 중 선택 | 사업소를 선택하세요 |
| 수거 희망일 | 날짜 | 예 | 오늘 이후 날짜만 | 오늘 이후 날짜를 선택하세요 |
| 수거 장소 유형 | 선택 | 예 | 사업소 또는 자택 | 수거 장소 유형을 선택하세요 |
| 수거 주소 | 텍스트 | 예 | 항상 입력 필수 | 주소를 입력하세요 |
| 전동침대 수량 | 정수 | 예 | 0 이상의 정수, 최소 한 품목이 1 이상 | 전동침대 수량을 입력하세요 |
| 휠체어 수량 | 정수 | 예 | 0 이상의 정수 | 휠체어 수량을 입력하세요 |
| 기타 소형 용구 수량 | 정수 | 예 | 0 이상의 정수 | 기타 소형 용구 수량을 입력하세요 |

**검증 로직**:
- 모든 품목 수량이 0이면 접수가 거부된다.
- 음수 또는 정수가 아닌 수량은 거부된다.
- 오늘 이전 날짜는 거부된다.
- 사업소, 수거 희망일, 장소 유형, 주소가 없으면 접수가 거부된다.
- 주소는 장소 유형과 무관하게 항상 필수 입력.

### 2.2 상태 흐름

| 현재 상태 | 다음 상태 | 변경 시각 기록 | 화면 알림 |
|-----------|----------|----------------|----------|
| 접수 | 수거완료 | 예 | 예 |
| 수거완료 | 소독완료 | 예 | 예 |
| 소독완료 | 배송완료 | 예 | 예 |
| 배송완료 | (종료) | 완료일 기록 | 예 |

**규칙**:
- 현재 상태의 바로 다음 상태로만 변경 가능
- 중간 상태를 건너뛰는 변경 거부
- 역방향 변경 거부
- 접수 정보는 접수 상태에서만 수정 가능
- 접수 삭제 허용 안 함

## 3. 모바일·PC 레이아웃

### 3.1 모바일 레이아웃 (375px 기준)

**접수폼**:
- 모든 필드를 세로로 배치
- 각 필드 레이블 → 입력 필드 순서
- 품목 수량은 카운터 형태 (증감 버튼 + 입력란)
- 접수 생성 버튼은 화면 하단에 고정

**목록 화면**:
- 테이블을 세로 스크롤로 표시
- 열은 최소화 (접수번호, 상태, 수거 희망일)
- 상세 보기는 카드 형태로 전체 정보 표시

**상세 화면**:
- 필드를 세로로 배치
- 상태 변경 버튼은 화면 하단에 고정
- PDF 다운로드 버튼은 소독완료 상태부터 표시

**통계 대시보드**:
- 각 통계 항목을 카드 형태로 세로 배치
- 숫자는 크게 표시

### 3.2 PC 레이아웃 (1200px 기준)

**접수폼**:
- 사업소, 수거 희망일, 장소 유형을 가로로 배치
- 품목 수량을 가로로 배치
- 주소 입력란은 넓게 표시

**목록 화면**:
- 테이블을 전체 너비로 표시
- 필터 영역을 상단에 배치
- 열은 모두 표시 (접수번호, 사업소, 수거 희망일, 상태, 전체 수량)

**상세 화면**:
- 좌우 레이아웃: 좌측에 기본 정보, 우측에 상태 정보
- 상태 변경 버튼은 우측 하단에 배치

**통계 대시보드**:
- 통계 항목을 2열 또는 3열 그리드로 배치
- 각 카드에 숫자를 크게 표시

### 3.3 반응형 규칙

- 모바일 너비 이하에서는 세로 배치로 전환
- PC 너비 이상에서는 가로 배치로 전환
- 가로 스크롤에 의존하지 않도록 모든 화면 설계
- 핵심 흐름은 모바일에서도 수행 가능

## 4. 화면 알림

**발생 시점**:
- 접수 생성
- 수거완료 전환
- 소독완료 전환
- 배송완료 전환

**표시 방식**:
- 화면 상단에 알림 메시지 표시
- 5초 후 자동 사라짐
- 색상만으로 상태 구분하지 않음 (아이콘 + 텍스트)
- 스크린리더 지원: role="status", aria-live="polite" 속성 적용
- 알림 텍스트은 상태 변경 내용을 명시적으로 포함 (예: "접수번호 1234, 수거완료 전환")

---

## 5. PDF 다운로드

**조건**: 소독완료 상태부터 다운로드 가능
**형식**: 빈 PDF (1단계에서는 실제 공단 양식 데이터 삽입 안 함)
**흐름**: 상세 화면에서 PDF 다운로드 버튼 클릭 → 파일 다운로드

---

## 6. 엑셀 다운로드

**조건**: 현재 필터 결과 기준
**필수 열**:
- 접수번호
- 사업소
- 수거 희망일
- 수거 장소 유형
- 수거 주소
- 전동침대 수량
- 휠체어 수량
- 기타 소형 용구 수량
- 상태
- 완료일

**검증**: 엑셀 값은 화면 및 저장 데이터와 일치해야 함

## 7. 접근성 체크리스트

| 항목 | 기준 |
|------|------|
| 레이블 | 모든 입력에 명시적 레이블 |
| 오류 메시지 | 모든 검증 오류에 명시적 메시지 |
| 색상 | 색상만으로 상태 구분하지 않음 |
| 키보드 | 키보드만으로 모든 조작 가능 |
| 대비 | 모든 텍스트와 배경 대비 4.5:1 이상 |
| 포커스 | 포커스 순서 논리적 |
| 스크린 리더 | 레이블과 상태 읽힘 |

## 8. 구현 인수 조건

### 8.1 접수

1. 초기 등록 사업소를 선택
2. 오늘 이후의 수거 희망일 선택
3. 사업소 또는 자택 선택, 주소 입력
4. 최소 한 품목 수량 1 이상 입력
5. 접수 생성
6. 접수번호, 접수 상태, 생성 시각 저장
7. 화면 알림 표시

### 8.2 입력 검증

- 모든 품목 수량이 0이면 접수 거부
- 음수 또는 정수가 아닌 수량 거부
- 오늘 이전 날짜 거부
- 사업소, 수거 희망일, 장소 유형, 주소 없으면 접수 거부

### 8.3 상태 흐름

1. 접수에서 수거완료로 변경
2. 수거완료에서 소독완료로 변경
3. 소독완료에서 빈 PDF 다운로드
4. 소독완료에서 배송완료로 변경
5. 각 변경 시각과 화면 알림 확인
6. 중간 상태 건너뛰기 변경 거부 확인
7. 배송완료 시 완료일 기록 확인

### 8.4 데이터 보존

1. 애플리케이션 종료
2. 애플리케이션 재실행
3. 접수 정보, 현재 상태, 모든 상태 변경 시각, 완료일 유지 확인

### 8.5 조회·통계·엑셀

1. 기간·사업소·상태 필터 결과 저장 데이터와 일치 확인
2. 접수 건수와 전체·종류별 품목 수량 일치 확인
3. 엑셀 다운로드
4. 엑셀 각 필수 열과 값 화면 및 저장 데이터와 일치 확인

### 8.6 화면

- PC Chrome에서 접수부터 배송완료까지 수행 가능
- 모바일 너비에서 가로 스크롤에 의존하지 않고 핵심 흐름 수행 가능
- 모든 입력에 식별 가능한 레이블과 검증 오류 메시지 있음
- 상태를 색상만으로 구분하지 않음
