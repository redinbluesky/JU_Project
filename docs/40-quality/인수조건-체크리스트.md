## 1. 접수 (Scope 8.1)

### QA-001 [정상] 접수 생성 — 정상 흐름
- **근거 요구사항**: Scope 8.1 항목 1~7
- **사전조건**: 애플리케이션 기동, H2 파일 DB 초기화 완료
- **입력**: 사업소(OFFICE-001), 수거 희망일(오늘+1일), 장소 유형(사업소), 주소("광주광역시 OO로 OO"), 전동침대 1, 휠체어 0, 기타 0
- **절차**:
  1. 접수폼 화면 접속
  2. 위 입력값 입력
  3. 접수 생성 버튼 클릭
  4. 화면 알림 확인
  5. DB에서 해당 접수 건 조회
- **기대 결과**:
  - 접수번호 부여됨
  - 현재 상태 `RECEIVED`(접수)
  - 생성 시각 기록됨
  - 화면 알림 표시됨
  - DB에 1건 저장됨
- **증거 위치**: 브라우저 화면 스크린샷, DB 조회 결과(`runtime/db/ju-project`), 로그
- **실행 방식**: 실제 브라우저 검증

### QA-002 [정상] 접수 생성 — 다른 사업소

- **입력**: 사업소(OFFICE-002), 기타 정상 입력
- **절차**: QA-001과 동일하게 접수 생성
- **기대 결과**: OFFICE-002로 접수 저장됨
- **증거 위치**: DB 조회 결과
